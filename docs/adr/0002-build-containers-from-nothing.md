# Build containers from nothing

`compose` emits a complete architecture-16 container from the model, IR sources, profile, and skin; it neither requires nor patches a backup. The layout and numbering follow the MIT-licensed harmony-explorations codec, the only known blueprint that rebuilds Logitech compiles byte-for-byte and builds an empty configuration. Patching a backup would contradict the offline-compose scenario and make compose unusable on a blank remote.

## Consequences

The emitter is the largest component. Golden tests against the reference codec's documented outputs are mandatory.
