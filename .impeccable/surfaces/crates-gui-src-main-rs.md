# Remote Rebirth GUI

## Scope

Native Iced desktop application, whole surface: Remote, My Devices, Buttons, Watch TV, Favourites,
Settings, and the shared shell. Operate mode; code-led build.

## Direction contract

THESIS: The GUI is an owner's manual you can operate. It refuses the category's default of a neutral
sidebar over a card dashboard; the remote is explained once, in one line drawing, and every key on
that drawing is numbered into the same work table.

OWN-WORLD: Uncoated manual stock (#F6F0E3) under ink (#23211C), one oxide spot (#B84E2A), grass for
confirmed state (#5B7153), and a cloth-bound cover rail (#8C3F25). Hairline rules, numbered callouts,
serif section headings, sans work text, mono only for codes and counts. No cards: pages, rules, and
marginal notes.

STORY: The owner sees their own remote drawn at size, finds the physical key, reads its number, and
changes the command on the facing page. Detect, Backup, Prepare, Commit and Read-Back read as
chapters of the same manual, not as a separate admin console.

FIRST VIEWPORT: Cloth rail left; paper sheet filling the window; title and one-line purpose; four
device tabs; two routing diagrams as a fold-out band; left page a numbered Harmony 300 line drawing
at ~300×470; right page the numbered key table with the command index beneath; Prepare write top
right, Backup beside it; status footer outside the sheet.

FORM: Candidate 3, "Owner's Manual", seed key f82c19ed. Raised by the acetate manual (stepped
fore-edge rail), the exposure record (cross-hatched conflict), the cassette j-card (Backup and current
as two sides), the event catalog (fixed command cells), and Metro tiles (next step peeks in).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the
verdict, DESIGN.md, and every shipping raster carrying its provenance.
